⭐ Project Description (GitHub-Ready)

DocMind is an intelligent PDF Question-Answering application built using NLP and classical Machine Learning techniques.
It allows users to upload any PDF document and instantly retrieve accurate answers to natural-language questions based on the document’s content.

The system extracts text automatically from the PDF, preprocesses it, splits it into meaningful sentences, and builds a searchable knowledge base using TF-IDF vectorization and cosine similarity.
An enhanced keyword-boosting mechanism ensures high answer accuracy even when user queries do not exactly match the sentences in the document.

This lightweight, dependency-friendly application runs on any machine without requiring heavy AI frameworks like PyTorch or Transformers.
It is fast, efficient, and designed for real-world tasks such as reading reports, resumes, research papers, and technical documents
